# quality-in 质量工具二维矩阵

> 一句话总览：quality-in 工具地图原将质量工具按"基础统计—专项改进—体系管理—战略改进"四层导航；本文件将其重新组织为**二维矩阵**，便于按"场景 × 深度"精准选型。

## 矩阵读法（怎么用）
- **纵轴 = 深度三档**（工具下沉的层次，决定"用多重的武器"）：
 - ① **单一质量工具（点工具）**：解决一个具体数据/现象问题的最小单元（一张图、一个表、一次计算）。
 - ② **基础方法论（组合工具解一类问题）**：把若干点工具组合成套路，系统性解决某一类问题（如 FMEA 解"设计风险"、8D 解"客户投诉"）。
 - ③ **系统方法论（组织级范式）**：贯穿组织/全流程的范式与体系（如 APQP、TPS、TQM、QFD 展开、Quality 4.0）。
- **横轴 = 五大场景**（质量活动发生的价值链环节）：产品规划 → 产品开发 → 采购 → 生产制造 → 售后服务。
- **读法**：先定场景（列），再按问题复杂度选深度（行）。简单数据问题用①，一类反复问题用②，跨流程/组织问题用③；不要越层滥用（现场小问题不必上 DMAIC，组织级问题不能只靠一张柏拉图）。
- 单元格内为"该场景该档"对应的工具/方法名，可多行列出；名称后括注其上游代表（如 FMEA 属②、APQP 属③）。

## quality-in 原四层 ↔ 二维对应关系
| quality-in 原四层 | 对应二维位置 | 说明 |
| --- | --- | --- |
| ① 基础统计工具 | 主要落在 **纵轴①（单一质量工具）** | 控制图/SPC/直方图/柏拉图/因果图等点工具，多用于生产制造、产品开发现场 |
| ② 专项改进工具 | 主要落在 **纵轴②（基础方法论）** | APQP/FMEA/PPAP/SPC/8D/DOE 等"解一类问题"的组合套路 |
| ③ 体系管理工具 | 主要落在 **纵轴③（系统方法论）** 的"体系合规"维度 | ISO9001/IATF16949/VDA6.3/过程方法/供应商管理 SQM 等 |
| ④ 战略改进方法论 | 主要落在 **纵轴③（系统方法论）** 的"组织级范式/战略"维度 | 六西格玛/TPS/精益六西格玛/QFD/卓越绩效/TQM/Quality 4.0 |

> 注：四层是"按深度堆叠"，二维是"按场景 × 深度定位"；二者互补——二维矩阵的每一格都可回查四层归属。

## 选格示例（对照原四层）
- 产品规划 × 系统方法论 = **QFD / VOC 展开 / 质量目标展开**（对应原④战略层）
- 产品开发 × 系统方法论 = **APQP 五大工具**（对应原④战略层 + 原②专项）
- 产品开发 × 基础方法论 = **FMEA(DFMEA) / 田口稳健设计 / DOE**（对应原②专项）
- 采购 × 基础方法论 = **供应商审核 / PPAP / 来料检验**（对应原②专项）
- 生产制造 × 单一工具 = **控制图 / SPC / 直方图 / Poka-Yoke**（对应原①基础统计）
- 生产制造 × 基础方法论 = **5S / 看板 / 8D**（对应原②专项）
- 售后服务 × 基础方法论 = **8D / 客户投诉分析 / FRACAS**（对应原②专项）

## 使用提示
- 由下而上打地基：先会用①点工具，再用②方法论解一类问题，靠③系统方法论固化与驱动。
- 场景贯通：产品规划(QFD) → 产品开发(APQP/FMEA/DFSS) → 采购(SQM/PPAP) → 生产制造(TPS/SPC/8D) → 售后服务(8D/FRACAS/SERVQUAL) 形成质量链闭环。
- Quality 4.0 强调用数据/AI/IoT 把传统工具升级为数字化能力（生产制造、售后服务场景尤甚）。
