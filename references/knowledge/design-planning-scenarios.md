## §1 产品开发车间 · NPI/APQP · 需求错配 / 设计风险 / 门控失效

**场景定位**：新产品导入（NPI）阶段的质量管控——从需求转化到转量产，设计风险与门控失效是核心失效模式。

### 典型缺陷

- 需求错配（VOC→CTQ 映射断裂）
- 设计风险未识别（DFMEA 缺失/不完整）
- 转产失控（Ppk 未达标即量产）
- 门控失效（评审走过场）

### 场景 → 工具映射

| 工具 | 用途 | 判据 |
|------|------|------|
| B06 APQP | 五阶段门控主线 | 每阶段门审交付物齐全 |
| B01 FMEA（DFMEA/PFMEA）| 设计/过程风险识别 | DFMEA 完成率 100% · RPN 高项有对策 |
| F09 质量门 | 制造/项目节点把关 | 门审不通过不放行 |
| B03 PPAP | 生产件批准 | Ppk≥1.67（试产）· PSW 批准 |
| B15 DFSS | 六西格玛设计 | IDDOV/DMADV 阶段输出 |
| B04 DOE | 参数窗口验证 | 设计参数最优区间锁定 |

### 岗位

DQE（设计质量工程师）+ 研发 + 质量门评审组（跨职能）

### 领域挂载

- 主领域：B 设计
- 次领域：R 风险（FMEA/FTA 应用）

## §2 产品规划场景 · 需求洞察 / 目标对齐 · 优先级错配 / 战略漂移

**场景定位**：质量战略与年度目标规划——需求洞察、方针展开、优先级对齐。

### 典型缺陷

- 优先级错配（资源投向非关键质量特性）
- 战略漂移（方针未展开到执行层）
- 目标不一致（部门目标与公司质量目标脱节）

### 场景 → 工具映射

| 工具 | 用途 | 判据 |
|------|------|------|
| C05 VOC | 顾客之声采集 | VOC→CTQ 映射完整 |
| C04 KANO | 需求分类（魅力/期望/必备）| 魅力需求识别 |
| C06 方针管理 Hoshin | 方针逐层展开 | 展开覆盖率 100% |
| C10 X-Matrix | 战略部署矩阵 | 目标-措施-指标对齐 |
| C12 NPS / CSAT | 客户满意度基线 | 满意度目标达成 |

### 岗位

质量经理 + 战略层（董事会/CEO）+ 业务层（各部门）

### 领域挂载

- 主领域：F 战略
- 次领域：Q 客户（VOC/KANO/NPS）
