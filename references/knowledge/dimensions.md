# 质量管理四维交叉拆解索引（战略 / 过程 / 工具 / 改进）

> 一句话定位：本文件是对 QCM Skill 现有 `references/` 素材的交叉索引——按"战略 / 过程 / 工具 / 改进"四个维度，将 20 位大师、37+ 本著作、企业案例与 quality-in 二维工具矩阵重新组织，便于"先定维度再查深度"。
> 编号引用与 `SKILL.md` 人物索引、`books.md` 书单一致。

## 一、战略层面（Strategic）：质量作为经营 / 系统战略

**定义**：战略层面把质量从"事后检验"提升到"经营决策"层，以系统观统筹顾客价值、质量成本与竞争力，使质量成为企业顶层战略语言而非质检部门职能。它回答"质量在企业里到底处在什么位置、由谁对质量负责"这一根本问题。

**代表人物**
- #02 戴明：深刻知识系统 + 14 点，以系统观重塑经营哲学，TQM 思想源头——战略层面的"系统变革"角色。
- #03 朱兰：适用性（Fitness for Use）定义质量 + 质量三部曲，把质量从车间提升到董事会——战略层面的"管理框架"角色。
- #04 克劳士比：零缺陷 + 质量免费，以 PONC/COPQ 把质量翻译成财务语言——战略层面的"质量成本范式"角色。
- #07 费根堡姆：首次命名 TQM，以质量成本整合全员质量经营——战略层面的"全面质量经营"角色。
- #20 久米均：质量经营（MBQ），以质量统筹企业经营战略与顾客价值——战略层面的"质量经营"角色。
- #21 德鲁克：目标管理 MBO + 自我控制 + 有效性，以"目标—衡量—责任"框架把质量目标逐级展开（方针管理 Hoshin 的理论源头）——战略层面的"目标治理骨架"角色。
- #14 泰勒：科学管理，以时间/动作研究把工作标准化、可测量、可复制，为"质量为可重复性"奠定最早工程基础——战略层面的"科学管理奠基 / 标准化"历史定位（注："可互换零件"属 Whitney / 福特大规模生产史实，非泰勒贡献，与本文件第 5 节岗位执行"标准作业"归口一致）。
- #17 福特：大规模生产与标准化，把质量锚定为可重复的稳定一致——战略层面的"规模化一致质量"角色。
- #18 哈默：BPR 业务流程重组，以结构性再设计阶跃式提升质量 / 成本 / 速度——战略层面的"流程战略重构"角色。
- #19 哈林顿：BPM/BPI，以过程管理统一质量改进与业务流程重组——战略层面的"过程管理粘合"角色。

**代表著作**
- #2 转危为安（Out of the Crisis，戴明 14 点与系统变革）
- #4 质量免费（Quality is Free，克劳士比，质量成本范式）
- #1 朱兰质量手册（Juran's Quality Handbook，朱兰，TQM 集大成）
- #18 某通信科技龙头管理之道（任正非质量高频词：大质量体系 / 质量优先 / 七个反对）
- #17 价值为纲（某通信科技龙头，质量与效益统一，财经支撑可持续经营）
- #10 质量管理与卓越绩效（Evans & Lindsay，波多里奇框架整合 TQM 与卓越绩效）
- #11 零缺陷（Quality Without Tears，克劳士比，质量作为管理政策）
- #39 管理的实践（Drucker，目标管理 MBO）/ #40 卓有成效的管理者（有效性，质量目标治理骨架）

**代表案例**
- 某通信科技龙头：以客户为中心的大质量体系、"质量优先、以质取胜"方针，把质量定义为"企业活命的根本"，质量内嵌全流程全价值链、质量绩效一票否决——战略定调的标杆。
- 日本 TQM（久米均）：以质量经营统筹企业，顶层承诺 + 全员参与的企业级 TQM 日常体系，质量即经营。
- 福特：大规模生产标准化与可互换零件，以流程一致换稳定质量——规模化质量战略的最早范式。

**工具应用**
- 战略部署（Hoshin / 方针管理，赤尾洋二）：适用产品规划与战略目标逐级展开，把战略落到部门与个人（quality-in 矩阵：产品规划 × ③ 系统方法论）。
- 质量成本 COPQ / PONC 分析（克劳士比 / 费根堡姆）：适用经营层沟通，把质量投入翻译为财务语言（books.md #30 现代质量成本管理、#29 质量与经济）。
- 波多里奇框架（Evans & Lindsay）：适用组织级卓越绩效自评与对标（books.md #10 / #28 卓越绩效准则）。
- 质量战略地图 / 平衡计分卡质量维度：适用把质量目标与财务、顾客、过程、学习成长维度对齐（quality-in 战略改进方法论层）。

## 二、过程层面（Process）：过程 / 系统设计与管理

**定义**：过程层面聚焦产品与服务的"过程本身"如何被设计、控制与优化，在研发与生产链路中把变异、浪费与失效风险前置到源头，使过程稳定且稳健。它回答"质量是如何被设计进流程、又如何在流程中被守住"的问题。

**代表人物**
- #01 休哈特：SQC 之父，控制图区分普通 / 特殊原因变异——过程层面的"统计过程控制"角色。
- #06 田口：稳健设计 + 质量损失函数，设计即质量——过程层面的"稳健参数设计"角色。
- #08 大野耐一：TPS，JIT + 自働化彻底消除浪费——过程层面的"精益过程流"角色。
- #09 新乡：SMED + Poka-Yoke 防错，源头不产生缺陷——过程层面的"防错 / 快速换模"角色。
- #12 赤尾洋二：QFD 质量屋，VOC → 技术需求——过程层面的"需求到设计展开"角色。
- #16 水野滋：QFD 共同提出者 + 新 QC 七工具——过程层面的"规划 / 策划工具"角色。
- #05 石川馨：因果图 + QC 七种 + 品管圈，全员参与——过程层面的"现场分析工具"角色。
- #18 哈默：BPR，流程根本性再设计——过程层面的"流程结构重构"角色。
- #19 哈林顿：BPM/BPI，可度量可持续的过程改进——过程层面的"过程管理"角色。

**代表著作**
- #5 丰田生产方式（大野耐一，TPS：JIT + 自働化）
- #12 田口方法（质量工程学导论，田口，稳健设计）
- #19 质量机能展开 / #20 质量功能展开——理论与方法（熊伟 / 马跃，QFD 质量屋）
- #21 统计过程控制理论与实践 / #22 统计过程控制技术（SPC、Cpk、DOE、MSA 一体化）
- #7 新丰田生产方式（门田安弘，TPS 系统解构：标准作业 / 看板 / 均衡化）

**代表案例**
- 丰田 TPS：JIT + 自働化彻底消除七大类浪费，看板拉动、安灯内建质量——过程流设计标杆。
- 某汽车集团产品开发：并购某北欧豪华品牌后导入 IATF16949 / VDA6.3、APQP 五大工具、GTSM 安全系统工程，覆盖研发—制造—供应链—售后全链条——产品开发过程体系。
- 某通信科技龙头 IPD 质量门：将质量要求内嵌 IPD 六阶段、5 DCP、6 TR（一票否决），"流程即质量、质量即流程"——过程关口设计。

**工具应用**
- SPC / 控制图（休哈特）：适用生产制造过程统计稳态监控（quality-in 矩阵：生产制造 × ① 单一工具），区分普通 / 特殊原因变异。
- QFD / 质量屋（赤尾洋二 / 水野滋）：适用产品规划 → 开发的需求逐级展开（矩阵：产品规划 / 产品开发 × ③ 系统方法论）。
- 稳健设计 / 参数设计（田口）：适用产品开发阶段的稳健性优化（矩阵：产品开发 × ② 基础方法论）。
- FMEA（DFMEA / PFMEA，福特 / AIAG-VDA）：适用设计 / 过程风险前置管控（矩阵：产品开发 × ② 基础方法论）。
- APQP 五大工具：适用汽车新产品先期策划（矩阵：产品开发 × ③ 系统方法论）。
- 过程能力 Cpk / Ppk：适用评价过程满足规格的能力（矩阵：生产制造 × ① 单一工具）。
- 价值流图 VSM：适用识别并消除价值流浪费（矩阵：生产制造 × ② 基础方法论）。
- 看板 / 均衡化（大野耐一）：适用拉动式生产与负荷均衡（矩阵：生产制造 × ② / ③ 系统方法论）。

## 三、工具层面（Tool）：单一质量工具点用

**定义**：工具层面把质量方法论落到具体"一张图、一个表、一次计算"的最小可执行单元，让一线用低门槛工具做数据分析、归因与防错。它是战略、过程、改进三层的执行底座，回答"今天到现场该用哪个工具"的问题。

**代表人物**
- #05 石川馨：因果图 + QC 老七工具 + 品管圈，全员参与现场——工具层面的"QC 七工具普及"角色。
- #01 休哈特：控制图，统计过程控制的起点——工具层面的"控制图 / SPC"角色。
- #13 谢宁：Red X 红 X 方法，高级根因定位——工具层面的"多变图 / 好件坏件对比"角色。
- #06 田口：正交表 + S/N 比，稳健性筛选——工具层面的"田口试验工具"角色。
- #09 新乡：Poka-Yoke 防错——工具层面的"防错装置 / 源流检验"角色。

**代表著作**
- #14 质量工具箱（The Quality Toolbox，约百种质量工具百科）
- #19 质量机能展开 / #20 质量功能展开——理论与方法（QFD 质量屋等工具）
- #21 统计过程控制理论与实践（控制图 / 过程能力 / DOE / MSA / PPM）
- #12 田口方法（正交表 / 参数设计）
- #23 可靠性工程 / #24 以可靠性为中心的质量设计（FRACAS / FTA 等可靠性工具）

**代表案例**
- quality-in 工具地图（生产制造场景）：控制图 / SPC、直方图、Cpk / Ppk、Poka-Yoke、柏拉图、散布图等点工具在生产制造现场的组合落地（quality-in 矩阵：生产制造 × ① 单一工具）。
- 某通信科技龙头质量度量：缺陷密度 / 测试覆盖率等度量工具，配合 IPD 质量门做质量"准出"判定。

**工具应用**
- QC 旧七工具（因果图 / 排列图 / 直方图 / 控制图 / 散布图 / 层别法 / 检查表，石川馨）：适用现场数值数据收集与问题分析（矩阵：生产制造 × ①）。
- 新 QC 七工具（亲和图 / 关联图 / 系统图 / 矩阵图 / 矩阵数据分析 / PDPC / 箭条图，水野滋）：适用非数值 / 策划类复杂课题（矩阵：产品规划 × ①）。
- SPC（休哈特）：适用过程波动监控与受控判定。
- MSA（测量系统分析）：适用保证数据可信，先于 DOE / 过程能力分析（矩阵：生产制造 × ② 专项改进）。
- FMEA：适用失效风险识别与优先级预防（矩阵：产品开发 × ②）。
- PPAP（生产件批准）：适用采购 / 供应商批准（矩阵：采购 × ②）。
- DOE（田口 / 六西格玛）：适用多因子筛选与稳健优化（矩阵：产品开发 × ②）。
- Poka-Yoke 防错（新乡）：适用源头杜绝缺陷（矩阵：生产制造 × ①）。
- Red X（谢宁）：适用顽固 / 反复根因定位（多变图 / 零件搜索 / 变量搜索）。
- 可靠性工具（FRACAS / FTA，books #23 / #24）：适用故障报告闭环与故障树分析（矩阵：售后服务 × ② / ③）。

## 四、改进层面（Improvement）：持续改进与突破

**定义**：改进层面以 PDCA（原旨为休哈特/戴明的 PDSA 循环）为底层节奏，通过渐进改善（Kaizen）与突破式改进（六西格玛 / Red X / 8D）结合，把一次性解题变为可复制、可闭环的组织能力。它回答"问题出现后如何既治标又治本、并防止复发"的问题。

**代表人物**
- #11 今井正明：Kaizen 改善，持续小幅改进——改进层面的"渐进改善"角色。
- #10 比尔·史密斯：六西格玛之父（Motorola），奠基 3.4ppm 缺陷目标——改进层面的"六西格玛奠基"角色（DMAIC 五阶段由后续 Harry 等体系化）。
- #15 Mikel Harry：六西格玛推广者与架构师，构建战略级改进体系——改进层面的"六西格玛架构化"角色。
- #13 谢宁：Red X，高级根因定位——改进层面的"顽固根因突破"角色。
- #04 克劳士比：零缺陷，质量免费——改进层面的"零缺陷文化 / 14 步"角色。
- #08 大野耐一：TPS 消除浪费——改进层面的"精益改善"角色。
- #01 休哈特：PDSA 雏形——改进层面的"改进循环骨架"角色。

**代表著作**
- #8 六西格玛管理统计指南（MINITAB，六西格玛 DMAIC 统计落地）
- #13 精益六西格玛（LSS，精益速度 + 六西格玛变异控制合一）
- #11 零缺陷（Quality Without Tears，克劳士比，无争执管理实现零缺陷）
- #6 精益思想（Lean Thinking，Womack & Jones，精益五原则）
- #15 质量管理传奇（汪泉发 等，系统梳理大师思想演变）

**代表案例**
- 六西格玛项目（某通信科技龙头 / 通用）：以 DMAIC 做数据驱动突破性改进，黑带 / 绿带梯队沉淀改进能力——突破式改进标杆。
- Kaizen（今井正明）：Gemba 现场改善 + 5S + 提案改善，全员日常渐进改进。
- 航空宇航双归零（改进闭环）：技术归零五条 + 管理归零五条，遵循 PDCA 把单次问题转化为组织级预防资产（books #37 归零）。
- 8D（汽车，福特）：团队导向八步法根因分析与闭环，适用客户投诉 / 重大异常。

**工具应用**
- PDCA（即 PDSA：Shewhart 循环、戴明推广；中文惯称 PDCA）：任何改进活动的底层节奏（各场景通用，矩阵：全场景基础节奏）。
- DMAIC（定义 / 测量 / 分析 / 改进 / 控制，史密斯 / Harry）：适用已有过程的突破式改进（矩阵：生产制造 × ③ 系统方法论）。
- DMADV / IDOV（DFSS，books #31）：适用设计阶段六西格玛（矩阵：产品开发 × ③ 系统方法论）。
- Kaizen / 改善（今井）：适用日常渐进、低本高效改进（矩阵：生产制造 × ② 基础方法论）。
- 8D（福特）：适用客户投诉 / 重大异常团队闭环（矩阵：售后服务 / 生产制造 × ②）。
- LSS（George，books #13）：适用既要提速又要降变异（矩阵：生产制造 × ③）。
- Red X（谢宁）：适用顽固 / 反复根因定位（多变图 / 零件搜索 / 变量搜索）。
- 5Why / 鱼骨图（石川馨）：适用因果归因（矩阵：售后服务 × ①）。
- A3：适用一页纸结构化改进报告。
