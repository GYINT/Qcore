# 多里安·谢宁（Dorian Shainin, 1914–2000, 美国）

> 一句话定位：Red X（红 X）方法论创立者，以简单而强大的统计实验技术做"高级根因定位"，与朱兰一脉相承。

## 核心理论（心智模型）
- Red X / Blue X 框架：把复杂变异问题中的"主导性根本原因"称为 Red X，次要原因称 Pink/Pale X，用实验而非争论锁定它。
- 多变图（Multi-Vari）：把过程总变异分离为"周期内/周期间/批间"等族系，可视化定位变异来源方向，大幅缩小排查范围。
- 好/坏对比定位法：以零件搜索（Component Search）、成对比较（Best-of-Best vs Worst-of-Worst）、变量搜索（Variable Search）等，用"好件 vs 坏件"对比快速逼近真正原因。

## 决策启发式（何时用 / 怎么用）
1. 当传统鱼骨图找不到根因、问题反复时，用多变图先看"变异来自哪一类"，再做针对性对比实验。
2. 用"好件 vs 坏件"配对比较替代主观争论，让数据指认 Red X。
3. 先定位（identify）再确认（confirm）：用变量搜索缩小变量集，最后用验证实验坐实根因。

## 代表工具与方法
- Red X 方法论
- 多变图（Multi-Vari Charts）
- 零件搜索（Component Search）
- 成对比较（Paired Comparisons / B vs C）
- 变量搜索（Variable Search）
- 预控制（Pre-Control）、公差平行四边形
