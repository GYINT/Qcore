# 流程模板

> **定位**：本文件定义 QCM 全字段格式的通用模板，适用于任何岗位/角色的多步工作流（复杂任务）。每步结构一致，按「上级门控 → 输入 → 动作 → 判据 → 产出 → 责任角色 → KPI → 子级里程碑」输出，配合计划线与时间尺。PD 工作流（`pd-qm-workflow.md`）是本模板的具体实例。

## 通用结构

```
① 步骤名称（周期） | 工具：[工具名]
- **上级门控**：↑ 本步启动的前提条件（前步产出/批准/资源）
- 输入：← 前步传递的文档/数据/物料
- 动作：本步所做的事（动词导向，串行步骤）
- 判据：量化的合格标准（含示例值及出处）
- 产出→下步输入：本步交付物
- 责任角色：主责 / 协同
- KPI：量化验收指标
- **子级里程碑**（长步用）：
  - M1 子段名 → 目标日期
  - M2 子段名 → 目标日期
```

## 字段说明

| # | 字段 | 说明 | 必填 |
|---|------|------|------|
| 1 | **步骤名称（周期）** | 动作名词 + 预计周期（如 W1–W2 / D0–D1） | ✅ |
| 2 | **工具** | 该步核心工具（VOC / QFD / DFMEA / 8D 等） | ✅ |
| 3 | **上级门控** | 本步启动前提条件（↑ 前步产出已评审/已批准/已签核） | ✅ |
| 4 | **输入** | 前步传递的内容（← 文档/数据/物料） | ✅ |
| 5 | **动作** | 动词导向的描述，串行连接 | ✅ |
| 6 | **判据** | 量化合格标准（含示例值、适用条件、标准出处） | ✅ |
| 7 | **产出** | 本步交付物（→ 下步输入） | ✅ |
| 8 | **责任角色** | 谁主责、谁协同 | ✅ |
| 9 | **KPI** | 量化的验收指标（含目标值） | ✅ |
| 10 | **子级里程碑** | 长步（≥ 2 周）拆内部子段，短步不拆 | ⚠️ 长步必填 |

## 适用场景

| 分类 | 使用模板 |
|------|---------|
| 复杂任务（多步工作流/跨岗协调/项目制） | **本模板（全字段）** + 计划线+时间尺表 |
| 简单任务（单步/单点问答/小型场景） | 精简三要素（原则+流程+依据），免去子级里程碑 |
