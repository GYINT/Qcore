# 流程分类层（Process Classification）

> v2.6.2 | 基于 IATF 16949 三大过程（COP/SP/MP）+ 流程管理 PPT

## 一、流程分类（双维度）

| 维度 | 分类 | 对应 IATF |
|------|------|----------|
| 流程层级 | 核心流程 vs 辅助流程 | COP vs SP |
| 流程性质 | 战略性 vs 经营性 vs 支持性 | MP vs COP vs SP |
| 改进收益 | 大/中/小 | 价值锚定⑳ |
| 改进风险 | 大/中/小 | 风险五维⑫ |

## 二、价值链双轨

```
主线（COP）: 产品规划→产品开发→采购→生产制造→售后服务
底座（SP）:  计划/组织/信息/财务/供应链 五支持链
治理（MP）:  M1环境→M2方针→M3资源→M4风险→M5审核→M6改进
           = 治理六层级管理动作显式映射
```

## 三、端到端核心流程

| 流程 | 起止 | 价值链 |
|------|------|--------|
| MTL 市场到线索 | 需求→线索 | 产品规划 |
| LTC 线索到回款 | 线索→订单 | 开发+采购 |
| OTC 订单到交付 | 订单→交付 | 生产制造 |
| ITR 问题到解决 | 问题→关闭 | 售后服务 |

## 四、能力建设六步链

```
诊断(年)→规划(季)→设计(季)→执行(日/周)→审计(季/月)→迭代(持续)
= 流程治理大循环 → 审计发现进入六步导航小循环 → 迭代回流标准
```
