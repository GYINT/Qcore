# PD 岗位质量工作流

> **定位**：PD（Product Development）在产品开发端用质量工具链串起"需求→设计→验证→量产"全线，上步产出即下步输入（APQP 五阶段 + 克劳士比预防前移）。本章按 QCM 默认精简格式（上级门控打头 + 子级里程碑列表 + 周期里程）输出。

## 流程分步

### ① 需求澄清（W1–W2） | 工具：VOC + CTQ Tree
- **上级门控**：↑ 客户需求已采集，立项批准已签核
- 输入：← 客户原始需求
- 动作：采集→分类→排序，提取关键质量特性
- 判据：CTQ 可测量、客户签字确认
- 产出→下步输入：CTQ 清单（量化含公差）
- 责任角色：PD 主责 / 产品经理 协同
- KPI：CTQ 客户确认率 = **100%**
- **子级里程碑**：
  - M1 需求采集完成 → W1 末
  - M2 CTQ 分类排序完成 → W2 中
  - M3 客户签字确认 → W2 末

### ② 方向分解（W3–W4） | 工具：QFD 质量屋
- **上级门控**：↑ CTQ 清单已客户签字
- 输入：← CTQ 清单
- 动作：CTQ → 可测量技术特性 + 目标值，建 HOQ
- 判据：映射率 100%；强相关标`◎`
- 产出→下步输入：技术特性矩阵（目标值 + 权重）
- 责任角色：PD 主责 / DQE 协同
- KPI：映射率 = **100%**；HOQ 完整性 ≥ **80%**
- **子级里程碑**：
  - M1 HOQ 左墙+天花板完成 → W3 末
  - M2 相关矩阵+权重完成 → W4 中
  - M3 设计目标发布评审 → W4 末

### ③ 因素识别（W5） | 工具：P-Diagram 参数图
- **上级门控**：↑ 技术特性矩阵已评审
- 输入：← 技术特性矩阵
- 动作：识别理想函数 y=f(x,z) 中控制因素 x、噪声因素 z
- 判据：噪声覆盖 5 类（外部/内部/退化/客户/环境）
- 产出→下步输入：P-Diagram 因素汇总
- 责任角色：PD 主责 / DQE 协同
- KPI：噪声覆盖 5/5 类
- **子级里程碑**：短步，不拆

### ④ 风险预防（W6–W9） | 工具：DFMEA 七步法
- **上级门控**：↑ P-Diagram 已评审 + 噪声覆盖 5/5
- 输入：← P-Diagram 因素汇总
- 动作：结构→功能→失效→起因→预防→探测→AP
- 判据：S ≥ 9 必有预防控制，AP 样件前关闭
- 产出→下步输入：DFMEA 矩阵（控制措施 + AP）
- 责任角色：PD 主导 / DQE 协同
- KPI：S>8 关闭率 = **100%**；按期完成率 ≥ **90%**
- **子级里程碑**：
  - M1 结构树完成 → W6 末
  - M2 失效链+S9-10 识别 → W7 末
  - M3 预防/探测措施草稿 → W8 末
  - M4 AP 高风险关闭+评审 → W9 末

### ⑤ 验证计划（W10–W18） | 工具：DVP&R
- **上级门控**：↑ DFMEA 高风险关闭 + 设计评审通过
- 输入：← DFMEA 控制措施
- 动作：为每项高风险/关键特性制定验证方案
- 判据：样品 ≥ 30；每项措施有验证节点
- 产出→下步输入：DVP&R 验证结果（合格/不合格清单）
- 责任角色：PD 主责 / DQE·测试 执行
- KPI：DVP 按期完成率 = **100%**；DV 一次通过率 ≥ **85%**
- **子级里程碑**：
  - M1 验证方案审批完成 → W10 末
  - M2 样品制作+测量 → W12–W16
  - M3 DV 测试完成 → W17 末
  - M4 验证报告评审通过 → W18 末

### ⑥ 生产准备（W19–W22） | 工具：控制计划 + PPAP
- **上级门控**：↑ DVP&R 全部通过 + 设计冻结
- 输入：← DVP&R 验证确认的设计输出
- 动作：CTQ → 过程参数/检具/抽样/反应计划，提交 PPAP
- 判据：控制计划覆盖所有 CTQ；量具 Gage R&R < 10%（示例）**
- 产出→下步输入：控制计划 + PPAP 批准
- 责任角色：PD 与质量共担 / SQE 协同
- KPI：PPAP 一次通过率 ≥ **90%**；CTQ 覆盖率 = **100%**
- **子级里程碑**：
  - M1 控制计划草稿+粗流程 → W19 末
  - M2 检具设计+MSA 完成 → W20 末
  - M3 试产+问题点关闭 → W21 末
  - M4 PPAP 提交并批准 → W22 末

### ⑦ 能力确认（W23） | 工具：Cpk + SPC 控制图
- **上级门控**：↑ PPAP 签署批准 + SOP 发行
- 输入：← 控制计划（规格限）
- 动作：量产首件/首批做短期 Cpk，建控制图基线
- 判据：Cpk ≥ 1.33（示例阈值，依客户规格）；特殊原因 24h 响应
- 产出：量产 Cpk 基线 + 控制图监控标准
- 责任角色：PD 交底 / PQE·制造 接收
- KPI：首月关键特性 Cpk ≥ 1.33 达成率 ≥ **95%**
- **子级里程碑**：短步，不拆

## 适用说明

- **复杂任务**（多步工作流）：执行上述全结构（上级门控/输入/动作/判据/产出/责任/KPI/子级里程碑 + 计划线+时间尺）
- **简单任务**（单步/单点问答/小型场景）：按 QCM 精简三要素（原则+流程+依据）即可，免去子级里程碑等展开

## 依据

APQP（AIAG 五大工具）；QFD（赤尾洋二 / 水野滋）；P-Diagram（田口玄一）；DFMEA 七步法（AIAG-VDA FMEA Handbook）；DVP&R / 控制计划 / PPAP（APQP）；Cpk ≥ 1.33 / Gage R&R < 10%（AIAG SPC/MSA 示例阈值，依客户/产品规格）；IATF 16949 8.3。
